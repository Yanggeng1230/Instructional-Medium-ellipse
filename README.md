# 教學媒體：橢圓
## 教學活動
- 利用 GGB 的模擬「釘子與細繩」。設定兩定點 \(F_1, F_2\)，滑桿控制繩長 \(2a\)。開啟「顯示痕跡」，拖動動點 \(P\) 畫出橢圓。 改變 \(2a\) 的數值，觀察圖形的變化。
- 將橢圓中心置於原點 \((0,0)\)。利用 GGB 標出長軸頂點\((a,0)\)、短軸頂點 \((0,b)\) 與焦點 \((c,0)\)。 推出標準式以及利用畫面上動態拉出一個直角三角形得出 \(a^2 = b^2 + c^2\) 的結論（也可改成直橢圓）
- 在 GGB 中設置改變中心點 \(M(h,k)\) 的滑桿，讓學生拖動中心點，觀察標準式如何改變
- 建立橢圓的「大圓（半徑 \(a\)）」與「小圓（半徑 \(b\)）」。從原點畫一條夾角為 \(\theta\) 的線，交小圓於 \(R\)，交大圓於 \(R\)。過 \(R\) 作垂直線，過 \(R\) 作水平線，交於 \(P\)。當動態改變 \(\theta\) 時，點 \(P\) 的軌跡剛好是橢圓。
