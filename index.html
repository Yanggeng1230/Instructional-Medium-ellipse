橢圓的定義

定義：

平面上到兩固定點 \(F_1, F_2\) 的距離和為 2a 的所有點所形成的圖形。
其中 \(F_1, F_2\) 稱為橢圓的焦點，兩焦點的距離為 2c。
★按下「開始動畫」，觀察P點的軌跡吧！

橢圓有兩條對稱軸：

長軸：通過兩焦點的對稱軸
短軸：與長軸垂直的對稱軸

中心在原點的方程式

水平橢圓 (橫向)

\[\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0)\]
  • 中心： \((0, 0)\)
  • 焦點： \((\pm c, 0)\)，在 x 軸上。
  • 長軸長： \(2a\) （水平），短軸長： \(2b\) （垂直）
  • 關係式： \(a^2 = b^2 + c^2\)

垂直橢圓 (直向)

\[\frac{x^2}{b^2} + \frac{y^2}{a^2} = 1 \quad (a > b > 0)\]
  • 中心： \((0, 0)\)
  • 焦點： \((0, \pm c)\)，在 y 軸上。
  • 長軸長： \(2a\) （垂直），短軸長： \(2b\) （水平）
  • 關係式： \(a^2 = b^2 + c^2\)

調整方程式參數

當前方程式:
\(\frac{x^2}{25.0} + \frac{y^2}{9.0} = 1\)

橢圓的標準式

當橢圓的中心不在原點 \((0,0)\)，而在點 \((h, k)\) 時，我們可以將原本中心在原點的方程式，透過坐標平移替換成 \(x - h\) 與 \(y - k\)。

\[\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1\]

（此處假設 \(a > b\)，為水平橢圓）

平移控制

\(\frac{x^2}{16} + \frac{y^2}{4} = 1\)

橢圓的參數式

利用三角函數的恆等式 \(\cos^2\theta + \sin^2\theta = 1\)，我們可以將橢圓方程式 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\) 轉換為由一個變數 \(\theta\) (參數) 控制的方程組。

\[ \begin{cases} x = a \cos \theta \\ y = b \sin \theta \end{cases} \quad (0 \le \theta < 2\pi) \]
